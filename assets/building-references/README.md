# Building References

Reference-only voxel architecture used to derive TinyWorld's worker construction grammar.

- `source/`: nine normalized source packages, preserving the supplied VOX/OBJ/MTL/preview files.
- `../../docs/building-reference-portfolio.md`: portfolio analysis, invariants, style grammar, optional moves, and developmental generations.

Do not insert these models directly as worker-built structures. Convert their visual language into a validated functional plan first.
